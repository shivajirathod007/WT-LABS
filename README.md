# WT-LABS

This academic repo contains the Web Technology lab assignments.

## Assignments

### AS-2: React Clock Dashboard

A responsive clock dashboard built with React and Vite.

- live analog clock
- digital clock display
- timezone selection
- dynamic world clock cards

Run it inside [assignment2/](assignment2):

```bash
npm install
npm run dev
```

### AS-3: Electricity Bill Calculator

A responsive Servlet-based electricity bill calculator.

- first 50 units: Rs. 3.50/unit
- next 100 units: Rs. 4.00/unit
- next 100 units: Rs. 5.20/unit
- above 250 units: Rs. 6.50/unit

Build it inside [AS-3/](AS-3):

```bash
mvn clean package
```
