# Electricity Bill JSP App

This small JSP app calculates electricity bills using the following slabs:

- First 50 units: Rs. 3.50/unit
- Next 100 units (51-150): Rs. 4.00/unit
- Next 100 units (151-250): Rs. 5.20/unit
- Units above 250: Rs. 6.50/unit

How to run:

1. Copy the `ElectricityBillJSP` folder into a Tomcat `webapps` directory (or deploy the containing project).
2. Open `http://localhost:8080/ElectricityBillJSP/index.jsp` in a browser.
