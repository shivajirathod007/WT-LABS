# Online Book Store

Responsive academic project built with React + TypeScript on the frontend and Spring Boot + MongoDB on the backend.

## Features

- Home page with hero section and store highlights
- Login page for existing users
- Catalogue page with book cards loaded from the backend
- Registration page that stores users in MongoDB

## Project Structure

- `frontend/` - React + TypeScript app
- `backend/` - Spring Boot REST API with MongoDB

## Backend Notes

- MongoDB database name: `online_book_store`
- API base path: `http://localhost:8080/api`

## Frontend Notes

- Uses React Router for page navigation
- Uses Axios for API calls
- Designed to be responsive for desktop and mobile screens
